# OET Listening 通勤リスニング

移動中に OET Listening の模試音源を「1文ずつ」聞き返すための iPhone 用 PWA（単一HTML・バニラJS）。

- **1文ずつ**：1文流れて止まる。もう1回／次の文
- **くり返し**：各文を2〜5回流して自動で次へ（文の間は無音。画面ロック中も進む）
- **通し**：止めずに流し、今の文を表示
- 英文は「聞いた後」に表示（隠す／常にも可）。☆で聞き返す文を集めて復習タブから順に再生
- イヤホン・ロック画面の ⏮ = もう1回、⏭ = 次の文
- 一度再生したパートは端末に保存され、圏外でも聞ける

## 教材の扱い

音源とスクリプトは市販・公式教材なので、**暗号化したものだけ**をこのリポジトリに置く。

- `a/<id>.bin` … 音声（モノラル AAC 32kbps）を AES-GCM で暗号化
- `data.enc.json` … 一覧・自動文字起こし（Whisper medium.en）・音声の鍵を、合言葉から PBKDF2-SHA256 で作った鍵で暗号化

元の音源・文字起こし・合言葉はリポジトリの外にある。

## 作り直し

```bash
~/whisper-env/bin/python build/prepare.py   # 圧縮＋文字起こし（未処理分だけ）
python3 build/build.py                      # 暗号化して a/ と data.enc.json を作る
node --test "tests/*.test.mjs"
```
